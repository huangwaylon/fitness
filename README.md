# Island Fund 🏝️ (working title)

A private, cozy, Animal Crossing–inspired fitness & healthy-eating motivation app for two people.
Healthy habits earn real money into a shared vacation fund (plus smaller treats like meals out).
Data flows automatically from Apple Watch / Apple Health — no manual importing.
